How it works

STEP 01

Install

Clone the repository and build the TypeScript CLI using pnpm in under two minutes.

STEP 02

Add your key

Export your API key as an environment variable or store it locally in user config with 0o600 permissions.

STEP 03

Run in your project

Point the harness at your target repository directory and tell it what task to accomplish.

Install guide

Prerequisites: Node.js 22 LTS or newer and pnpm (run corepack enable or npm i -g pnpm).

Linux 
$git clone https://github.com/rudrakshSoni-dev/AI-harness-claude-code.git harness
$cd harness
$pnpm install && pnpm build
$pnpm --filter @harness/cli link --global
$export HARNESS_API_KEY="sk-..."
$harness --dir ~/projects/my-app

Safety

The harness is jailed to the directory you choose using canonical realpath path checking. Relative path traversal (../) and symlinks leading outside your workspace root are strictly rejected.

Notice: This is a path jail and approval policy, not a container-grade sandbox. Approved shell commands run on your host. Always run the harness inside a directory tracked by git and inspect diffs before approving changes.

Shell commands (run_cmd) always require interactive confirmation. No command executes silently without your explicit approval.

Frequently Asked Questions

Where is my API key stored?

If you use HARNESS_API_KEY, it stays in your terminal session memory. If you run harness --setup, it is stored in ~/.config/harness/config.json with restrictive file permissions (0o600).

What data gets sent to external servers?

The harness communicates exclusively with your configured LLM endpoint via HTTPS. There is zero telemetry, zero analytics, and zero third-party tracking.

How much does it cost?

The harness software is completely free and open source. You pay only your chosen LLM provider for the tokens consumed by your prompts and completions.

How do I uninstall?

Unlink the global binary (pnpm unlink --global or npm unlink -g @harness/cli) and delete the cloned directory and config folder.
